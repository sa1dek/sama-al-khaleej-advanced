# مؤسسة سما الخليج المتقدمة للخدمات المنزلية

موقع ثابت باللغة العربية لخدمات النظافة والصيانة المنزلية في منطقة القصيم، ومنها بريدة وعنيزة. لا يحتاج إلى خادم تطبيقات أو قاعدة بيانات.

## تشغيل الموقع

يمكن فتح `index.html` مباشرة في المتصفح لمعاينة الصفحات. ولتشغيله عبر خادم محلي ثابت، افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. يمكن رفع المجلد كما هو إلى استضافة مواقع ثابتة، مع إبقاء المسارات النسبية كما هي.

## صفحات الموقع

- `index.html` — الصفحة الرئيسية.
- `pages/services.html` — الخدمات المنزلية.
- `pages/about.html` — نبذة عن المؤسسة.
- `pages/gallery.html` — معرض الصور ومقاطع الفيديو مع فلاتر حسب النوع.
- `pages/testimonials.html` — صفحة آراء العملاء.
- `pages/coverage.html` — المدن والمحافظات التي تغطيها الخدمات.
- `pages/contact.html` — معلومات التواصل ونطاق الخدمة.
- `pages/booking.html` — نموذج طلب الخدمة.
- `pages/404.html` — صفحة غير موجودة.

## بيانات يلزم تزويدها قبل الإطلاق

1. رقم واتساب والهاتف مضبوط على `+966562752902` في شريط التواصل ونموذج الحجز.
2. البريد الإلكتروني، وروابط حسابات التواصل الاجتماعي.
3. عنوان الموقع الإلكتروني النهائي لإعداد الروابط الأساسية وخريطة `sitemap.xml` وملف `robots.txt`.
4. العنوان التفصيلي إذا رغبت المؤسسة في إضافة خريطة.
5. ساعات العمل إذا رغبت المؤسسة في عرضها.

## إعداد الظهور في محركات البحث

بيانات العناوين والأوصاف وبيانات المؤسسة المركزية موجودة في `seo/metadata.json`. بعد تحديد النطاق الرسمي، ضعه في `siteUrl` بصيغة كاملة مثل `https://example.sa` ثم شغّل:

```bash
node scripts/build-seo.mjs
```

يكتب السكربت الوسوم داخل HTML مباشرة، ويضيف الروابط الأساسية وخريطة الموقع وسطر الخريطة إلى `robots.txt` عند توفر النطاق. الوسوم موجودة في ملفات HTML المنشورة نفسها حتى تكون قابلة للقراءة دون JavaScript. قد تختار محركات البحث صياغة مختلفة للعنوان أو الوصف، ولا تضمن الوسوم ترتيباً محدداً.

لا يحفظ نموذج الحجز بيانات الزوار. يجهز النموذج رسالة من البيانات المدخلة ويفتح محادثة واتساب؛ يضغط العميل إرسال لإيصال الطلب ثم تتواصل المؤسسة لتأكيد التفاصيل والموعد.

## التصميم والتقنيات

الموقع مبني باستخدام HTML وCSS وJavaScript عادي. جميع أنماط الصفحات، ألوان الوضعين، والتجاوب مجمعة في `css/style.css`. يستخدم الموقع خط تجوال وأيقونات Font Awesome من خدمات خارجية. يعمل التخطيط الأساسي دون JavaScript؛ وظائف القائمة والوضع اللوني والحجز والمعرض والعدادات وشريط التواصل تستخدم JavaScript. بيانات وسائط المعرض مفصولة في `js/data.js`، والملفات الإعلامية في `assets/img/`.
